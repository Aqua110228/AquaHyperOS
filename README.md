# AquaHyperOS

版本 26w40f - HyperOS 定制模块

## 功能特性

- 状态栏自定义
- 控制中心自定义
- 锁屏自定义
- 主题模糊效果
- 核心系统补丁
- 签名验证绕过
- 权限管理

## 系统要求

- Root 权限（静默获取）
- LSPosed 框架
- HyperOS 3.0+
- Android 12+

## 安装说明

1. 安装 LSPosed 框架
2. 安装 AquaHyperOS APK
3. 在 LSPosed 中激活模块
4. 授予 Root 权限（静默）
5. 选择作用域：android, com.android.systemui
6. 重启设备
